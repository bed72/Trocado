# Changes

## Spec não autoriza implementação
Quando o pedido for criar, revisar ou validar uma spec/OpenSpec, limite o trabalho aos artefatos da mudança e à validação deles. Não inspecione nem valide o projeto inteiro e não inicie implementação, testes da aplicação ou quality gate de código. Só aplique a mudança após autorização explícita do usuário para implementar/apply.
