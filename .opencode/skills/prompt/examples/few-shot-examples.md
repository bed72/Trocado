# Few-Shot Examples

## Feature request

Use `<workflow>` with: create and approve the spec, implement domain, infrastructure, data, presentation, providers and locations, then run `flutter analyze` and `flutter test`.

## Validator request

Use `<requirements> ### Technical` to mention `ValidationBase<T>`, `Validation<T>`, individual validators in presentation, and a feature-scoped `FormValidator`.

## API request

Include `<endpoints>` with the endpoint URL, HTTP method, expected status codes, request payload, and response mapping. Include `<tests>` for response parsing, repository behavior, and notifier state transitions.
