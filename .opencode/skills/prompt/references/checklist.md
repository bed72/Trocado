# Structured Prompt Checklist

- [ ] `<task>` is present and concise.
- [ ] `<goals>` is present and focused.
- [ ] `<role>` identifies a senior Flutter engineer, Flutter, Dart, Riverpod, Clean Architecture, and task context.
- [ ] `<requirements>` contains `Business`, `Technical`, and `UI/UX`.
- [ ] `<critical>` contains `Skills obrigatórias` and `Fora do Escopo`.
- [ ] The mandatory skill list contains `/sdd`.
- [ ] `<context-tools>` is included when project skills or MCPs apply.
- [ ] `<workflow>` is included when the task has dependent steps.
- [ ] `<output>` is included when file structure matters.
- [ ] `<endpoints>` is included for HTTP integrations with method, URL, and status codes.
- [ ] `<tests>` is included for any testable logic.
- [ ] Technical requirements name affected layers and the standard data flow.
- [ ] UI/UX requirements make applicable states explicit.
- [ ] Long blocks are separated with `---`.
- [ ] The response ends by instructing the user to execute `/sdd`.
